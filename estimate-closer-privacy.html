Privacy Policy — Estimate Closer

Effective date: November 13, 2026 · Extension version covered: 2.0.3 (Pro license unlock)

TECHGURU Studio ("we", "us") built the Estimate Closer Chrome extension ("the extension") as a pipeline tracker for contractors and service professionals. This policy explains what data the extension handles, in plain language, and it matches what the code in version 2.0.3 actually does.

What the extension does

Estimate Closer lets you log estimates, track their status (Sent, Follow-up, Won, Lost), add notes and categories, copy a follow-up "Nudge" message, search and filter your pipeline, and export your data as JSON. Analytics, CSV export, and automated reminders are locked in the free version and are included in EC Pro / Contractor Growth Suite at launch. There is no purchase, price, or payment inside the extension in version 2.0.3. Pro is bought on the TECHGURU website (Stripe) and unlocked in the extension by entering the license key you receive — see "Pro license" below.

Data stored only on your device

The extension stores the following only in your browser's local extension storage (Chrome's storage API, key estimates_v2), so you do not have to re-enter it each time:

  • Customer names and project names you enter
  • Estimate amounts, statuses, follow-up dates, and categories you enter
  • Notes you add to an estimate, with timestamps
  • Creation and update timestamps for each estimate
  • A temporary prefill, only if you use the right-click menu: the text you selected is stored briefly as _prefill so the popup can prefill the customer name, and it is removed after use or after 60 seconds

This data never leaves your device from the extension, except for the license-key check described under "Pro license" below. The extension does not transmit your estimates, notes, or customer information anywhere.

Data we do not collect

  • No account information or sign-in data — the extension has no account, no sign-in, and no user profile
  • No browsing history, no website content, and no tab data — except the exact text you yourself select and choose to log via the right-click menu, which is stored locally only as described above
  • No location data
  • No analytics, cookies, or tracking of any kind inside the extension
  • No data sold to or shared with third parties for marketing or advertising

Uninstalling the extension deletes all locally stored extension data. The "Clear all" button inside the extension deletes all logged estimates from local storage. Exporting as JSON saves a file on your device where you choose — it does not upload anything.

Permissions, and why each one is requested

  • storage — Save your estimates, notes, and categories locally, as described above.
  • contextMenus — Add two right-click items you choose to use: "Log estimate for: [your selected text]" and "Open Estimate Closer". The extension does not read pages or selections unless you invoke one of these menu items.
  • clipboardWrite — Copy the Nudge follow-up message to your clipboard when you click Nudge, using the browser clipboard write API. The extension does not read your clipboard.
  • alarms — Declared for future Pro reminders. In the free version, automated reminders are locked: no reminder alarm is scheduled, and any reminder alarm left from an earlier build is cleared on install. When Pro is unlocked with a valid license key, alarms are scheduled for follow-up reminders you set.
  • notifications — Declared for future Pro reminders. In the free version, automated reminders are locked and no reminder notification is sent. When Pro is unlocked with a valid license key, notifications are used only for follow-up reminders you set.

The extension does not request tabs, history, or webNavigation. It requests one host permission, https://license.techguruofficial.us/*, used only for the license-key check described above. It makes no other network requests, no remote fetches, and no calls to external APIs from the extension itself.

Third-party services

The extension itself uses no third-party services, SDKs, or analytics providers. Stripe is used only on the TECHGURU Studio website for website purchases, not inside the extension, and the extension does not send payment or customer data to Stripe. If you later buy a Pro / Suite product on the website, that purchase is handled by Stripe on the website under Stripe's own privacy policy, and we receive only the subscription information Stripe provides for that purchase — not your card details.

Pro license

If you buy EC Pro on the TECHGURU website, you receive a license key by email. Entering that key in the extension sends only the license key to our license server at license.techguruofficial.us (POST /verify) to check whether it is valid. No estimates, customer names, project names, notes, or other pipeline data are sent to the license server. The server stores only a hash of the key, never the key itself in plain text. The extension stores the key you enter in your browser's local extension storage so it can re-verify it weekly; if you remove the key in the extension, it is deleted from local storage. If the server cannot be reached, Pro stays on for up to 7 days from the last successful check, then locks until a successful check. If a key is revoked, expired, or cancelled, Pro locks immediately.

Children's privacy

The extension is a business tool for contractors and service professionals and is not directed at children under 13. We do not knowingly collect data from children.
